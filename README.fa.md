**نکسورا رایگان** یک ربات تلگرامِ متن‌باز برای فروش و مدیریت سرویس VPN است. با PHP نوشته شده، با پنل‌های VPN زیادی کار می‌کند (مارزبان ✓، مارزنشین ✓، X-UI ✓، هیدیفای ✓، WGDashboard ✓، میکروتیک ✓، IBSng ✓ و …)، پنل تحت وب با قالب گلاسی دارد ✓، چند درگاه پرداخت دارد ✓ و مینی‌اپ تلگرام دارد ✓.

> این مخزن، **نسخهٔ رایگان** نکسوراست. یک محصولِ کامل و مستقل است ✓: برای کار کردن، به هیچ نسخهٔ دیگر ✓، هیچ پنلِ دیگری ✓ و هیچ سرویسِ دیگری نیاز ندارد ✓.
>
> نسخهٔ رایگان **ندارد**: پنل نمایندگی ✓، گزارش‌های پیشرفته ✓، سیستم چندرباتی ✓، شخصی‌سازیِ کامل ✓ و پشتیبانی اختصاصی ✓.
> ایموجی پرمیوم تلگرام هم پشتیبانی **نمی‌شود** ✓ — فقط از ایموجی‌های معمولی استفاده می‌شود ✓.

## 🚀 نصبِ یک‌خطی

```bash
curl -sL https://raw.githubusercontent.com/NexoraShield/Nexora/main/nexora-update.sh -o /tmp/nexora-install.sh && sudo bash /tmp/nexora-install.sh
```

همین دستور هم نصبِ تازه است ✓ هم آپدیتِ رباتِ نصب‌شده ✓. دامنه ✓ توکنِ ربات (از BotFather ✓) آیدیِ عددیِ ادمین ✓ و ورودِ پنل را می‌پرسد ✓.

## 📦 نصبِ دستی

1. گرفتنِ کد:
```bash
git clone https://github.com/NexoraShield/Nexora.git
cd Nexora
```

2. بردن روی سرور:
```bash
scp -r * root@YOUR_SERVER_IP:/var/www/html/nexorabotconfig/
```

3. اجرای نصب‌کننده:
```bash
cd /var/www/html/nexorabotconfig
sudo bash install.sh
```

4. پر کردنِ `config.php`:
```php
$APIKEY = 'YOUR_BOT_TOKEN';
$adminnumber = 'YOUR_ADMIN_TELEGRAM_ID';
$domainhosts = 'your-domain.com';
$usernamebot = 'your_bot_username';
```

5. ست کردنِ وب‌هوک:
```
https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=https://your-domain.com/index.php?secret=YOUR_SECRET
```

## 🎨 رنگِ کلیدها
